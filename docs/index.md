# NixOS Configuration

Welcome to my personal NixOS configuration repository. This project contains the complete configuration for my Nix-based systems, including NixOS, Nix on Droid, and macOS.

## Overview

This repository is managed using Nix Flakes, which allows for reproducible and declarative system configurations. The structure is designed to be modular and easy to manage across multiple machines.
