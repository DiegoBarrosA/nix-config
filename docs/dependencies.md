This project relies on the following external dependencies, which are managed by Nix Flakes:

- **nixpkgs**: The official Nix package repository.
- **home-manager**: For managing user environments.
- **nix-on-droid**: For supporting Android devices.
- **sops-nix**: For managing secrets.
- **nix-darwin**: For supporting macOS.
