- **Nix**: A powerful package manager for Linux and other Unix-like systems that makes package management reliable and reproducible.
- **NixOS**: A Linux distribution built on top of the Nix package manager. It uses a declarative configuration model.
- **Flakes**: A new feature in Nix that improves reproducibility and composition of Nix-based projects.
- **Home Manager**: A tool to manage a user's environment using the Nix package manager.
- **Overlay**: A mechanism in Nix to customize or add packages to the Nixpkgs package set.
- **Module**: A reusable unit of NixOS or Home Manager configuration.
